**Yes.** All packages include complete source code with no obfuscation. You own the code after purchase.

### Can I resell this to my clients?
**Starter/Professional:** No reselling rights.
**Enterprise:** White-label reselling available with separate agreement.

### What if I need features not listed?

Yes. The interface is responsive and works on tablets. Ideal for tablet-based POS setups.
